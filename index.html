    설정

    기기 간 동기화 코드(PIN)를 여기서 연결·관리합니다.

    동기화 코드 이 기기에만 저장됨 (코드 연결 시 모든 기기 동기화)

    사용 방법 — 아무 숫자나 코드로 정해서 입력 후 "연결"을 누르세요. 다른 기기(가족 폰 등)에서 같은 앱을 열고 똑같은 코드를 입력하면, 체크리스트·일정 완료 표시가 그대로 불러와지고 이후 자동으로 서로 동기화됩니다.

    주의 — 코드를 다르게 입력하면 서로 다른 저장공간이 되어 동기화되지 않습니다. 가족과 반드시 같은 코드를 사용하세요.
